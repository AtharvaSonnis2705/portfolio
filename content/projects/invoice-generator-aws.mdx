## Problem

Freelancers and small shops often build invoices by hand in a document editor, then export, attach and email them one by one. The goal: fill a form once, and get a well-formatted PDF that is stored safely and delivered to the client automatically.

## Approach & key decisions

**Serverless over a long-running server.** Invoice generation is bursty — nothing for hours, then a batch at month end. AWS Lambda behind API Gateway means paying per request and never managing a box.

**Render PDFs on the server.** PDFKit runs inside the Lambda, so every invoice looks identical regardless of the user's browser, and the client receives a real PDF file rather than a printed web page.

**QR codes inside the PDF.** Each invoice embeds a QR code generated at render time. <Todo>Say what the QR code encodes (payment link, invoice URL, UPI ID…).</Todo>

**S3 for storage, SES for delivery.** The rendered PDF is written to S3 and sent through SES, which handles email deliverability.
