## Problem

Brands choosing an influencer usually look at follower counts and views. Those say nothing about the _audience_: is the comment section toxic, does the creator already run a lot of sponsorships, and do viewers actually engage?

## Approach & key decisions

**Use the comments, not just the counts.** The backend pulls a channel's recent videos and their comments through the YouTube Data API, then scores them, so the dashboard reflects how the audience behaves.

**Separate collection from presentation.** A Node.js backend handles API quotas and scoring; the React dashboard only renders the aggregated results.
